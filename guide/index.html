🎒준비물

딱 세 가지만 있으면 됩니다.

구글 계정 — 구글 Colab을 쓰기 위해 필요해요. 가입은 무료입니다.
인터넷 브라우저 — 크롬을 추천합니다. 설치할 프로그램은 없어요. 전부 웹에서 돌아갑니다.
비밀 값 3종 — DB 접속정보 · OpenAI 키 · (선택) GitHub 토큰. 담당 선생님이 따로 알려줍니다. 등록 방법은 아래 비밀 등록에서!
🔐 비밀번호·API 키는 프로그램 코드에 적지 않습니다. 대신 Colab의 🔑(비밀) 기능으로 안전하게 넣어요. (그래서 이 프로그램은 공개돼도 안전합니다)

🎯딱 한 곳만 고치면 됩니다

세 노트북 맨 위에는 “⚙️ 분석가 설정” 셀이 있어요. 세 노트북 모두 글자까지 똑같은 셀입니다. 여기 값만 바꾸세요. 나머지 셀은 손대지 않아요.

분석할 기업STOCK_CODE · COMPANY_NAME · SEARCH_KEYWORD · TOPIC_CODE
주가 옵션(1)STOCK_START_DATE · CHART_YEARS · BUY_DATE · INVEST_AMT
뉴스 옵션(3)START_DATE · END_DATE · PHOTO_TYPE · REG_START_OFFSET
비밀(자동)DB·OpenAI·GitHub → 🔑 비밀에서 자동으로 읽음 (코드 수정 불필요)
🏷️ 다른 기업으로 바꾸려면? “분석할 기업” 네 줄만 바꾸면 끝! 예) 삼성전자 → STOCK_CODE='005930', 이름·검색어를 ‘삼성전자’로.

🔑비밀 등록하기 (한 번만)

Colab을 열면 왼쪽에 열쇠 모양 🔑 메뉴가 있어요. 거기에 비밀 값을 넣어두면, 프로그램이 알아서 꺼내 씁니다.

Colab 화면 왼쪽 끝의 🔑 (비밀) 아이콘을 클릭합니다.
“새 보안 비밀 추가”를 눌러 아래 이름들을 하나씩 추가하고, 값은 선생님이 준 것을 붙여넣습니다.
각 항목의 “노트북 액세스” 스위치를 켭니다(파란색). 이걸 켜야 프로그램이 읽을 수 있어요.
# 🔑 비밀 메뉴에 넣을 이름들 (값은 선생님이 따로 알려줌) DB_HOST # 데이터베이스 주소 DB_USER # 아이디 DB_PASSWORD # 비밀번호 OPENAI_API_KEY # 3단계(뉴스 분석)에서만 필요 GITHUB_TOKEN # 3단계 끝의 HTML 업로드용 (선택)
⚠️ 비밀 값을 친구에게 채팅으로 보내거나 코드에 직접 적지 마세요. 꼭 🔑 비밀 메뉴에만 넣습니다.

▶️이제 실행! 세 단계

각 버튼을 누르면 새 탭에서 Colab이 열립니다. 열리면 메뉴의 런타임 → 모두 실행을 누르거나, 셀을 위에서 아래로 ▶ 눌러 실행하세요.

📈 1단계 · 주가 분석

네이버에서 주가를 모아 캔들차트·이동평균·RSI·MACD·볼린저밴드, 그리고 “그때 샀으면?” 투자 시뮬레이션까지 보여줍니다.

🚀 Colab에서 1단계 열기

💰 2단계 · 재무 분석

매출·당기순이익·총자산과 6대 재무비율(수익성·성장성·안정성·유동성·활동성·PBR)을 표와 레이더 차트로 정리합니다.

🚀 Colab에서 2단계 열기

📰 3단계 · 뉴스·ESG 분석

뉴스를 모아 AI로 감성(긍정·부정)과 ESG 이슈를 분류하고, ESG 감성지수가 주가에 영향을 주는지 회귀분석까지 합니다. 마지막엔 예쁜 HTML 보고서도 만들어요.

📌 3단계는 1·2단계가 만든 데이터를 씁니다. 반드시 1 → 2 → 3 순서로 실행하고, 🔑 비밀에 OPENAI_API_KEY가 있어야 합니다.
🚀 Colab에서 3단계 열기
🔧 3단계가 더 똑똑해진 점 (궁금한 사람만)
  • 차단 방지 수집 — 네이버가 막으면 잠깐 쉬었다 다시 시도(지수 백오프), 사람처럼 보이는 접속, 못 받은 달은 따로 기록합니다.
  • 회귀 기간 조절 — REG_START_OFFSET로 회귀분석 시작 연도를 조정할 수 있어요(0=전체).
  • 진행 표시 — 셀마다 “지금 몇 번째 단계”인지 알려줘서 길을 잃지 않아요.

🔁이 순서만 기억하세요

📈 1 주가 → 💰 2 재무 → 📰 3 뉴스·ESG

각 노트북 안에서는 셀을 위에서 아래로 실행만 하면 됩니다.

🆘막히면 여기

❓ “DB 비밀 미설정” 이라고 떠요

🔑 비밀 메뉴에 DB_HOST · DB_USER · DB_PASSWORD를 넣고 노트북 액세스를 켰는지 확인하세요. 값은 선생님께 받습니다.

❓ 3단계에서 오류가 나요

1·2단계를 먼저 끝냈는지, OPENAI_API_KEY를 등록했는지 확인하세요. 3단계는 1·2단계 데이터가 있어야 동작합니다.

❓ 뉴스가 잘 안 모여요

네이버가 일시적으로 막은 것일 수 있어요. 3단계는 자동으로 쉬었다 다시 시도합니다. 잠시 후 다시 실행하면 이어서 모읍니다.

❓ 다른 회사를 분석하고 싶어요

맨 위 “⚙️ 분석가 설정” 셀의 기업 네 줄(코드·이름·검색어·TOPIC_CODE)만 바꾸고, 세 노트북에 똑같이 적용하면 됩니다.

❓ 노트북을 내 드라이브에 저장하려면?

Colab에서 파일 → 드라이브에 사본 저장을 누르면 내 구글 드라이브로 복사됩니다. 그 사본에서 자유롭게 수정·실행하세요.
